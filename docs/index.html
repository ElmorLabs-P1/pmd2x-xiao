PMD2X XIAO Firmware Installer

Flash firmware to a Seeed Studio XIAO ESP32C6 connected to your ElmorLabs PMD2X directly from this page. Works in Chrome or Edge on desktop or Android (Web Serial is not supported in Safari or Firefox). Connect the XIAO over USB first, then click Install below and pick its serial port when prompted.

Dashboard __VERSION__

Web dashboard with live telemetry, WiFi setup page, captive portal, and BLE provisioning. Recommended for most users. After flashing, power-cycle the PMD2X itself (not just the XIAO) before reconnecting — otherwise it may keep reporting stale or all-zero sensor readings.

Quick start

  1. On your phone or laptop, connect to the WiFi network PMD2-Dashboard (password pmd2pmd2).
  2. A setup page should open automatically; if not, visit 192.168.4.1 and enter your home/office WiFi network and password.
  3. Once connected, visit pmd2.local on that same WiFi network to open the dashboard.

SPI Command Tester

Minimal serial-only command tester. Mainly useful for development and debugging the SPI link to the PMD2X. Its optional WiFi console needs your network's SSID and password compiled in, so it isn't available as a one-click flash here — grab the source and build it yourself in the Arduino IDE instead.

Download PMD2_XIAO_ESP32C6_SPI_Master.ino
