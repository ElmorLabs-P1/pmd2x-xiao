PMD2X XIAO Firmware Installer

Version __VERSION__. Flash firmware to a Seeed Studio XIAO ESP32C6 connected to your ElmorLabs PMD2X directly from this page. Works in Chrome or Edge on desktop or Android (Web Serial is not supported in Safari or Firefox). Connect the XIAO over USB first, then click Install below and pick its serial port when prompted.

Dashboard

Web dashboard with live telemetry, WiFi setup page, captive portal, and BLE provisioning. Recommended for most users.

SPI Command Tester

Minimal serial-only command tester. Mainly useful for development and debugging the SPI link to the PMD2X.

Firmware is rebuilt and published here automatically from the pmd2x-xiao repository whenever a new version is tagged. After flashing the Dashboard firmware, see the repo's README for how to connect it to your WiFi network.
